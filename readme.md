# Falcons: Распределенная система интернет-магазина

## Архитектура системы

Система разделена на три независимых сервиса, каждый из которых изолированно решает свою бизнес-задачу. Сервисы общаются между собой по внутренней сети Docker.

### 1. Django Core (Порт `8000`)
Монолит системы, управляющий критически важными бизнес-процессами.
* **Технологии:** Django, Django REST Framework, SQLite, SimpleJWT.
* **Зона ответственности:** 
  * Регистрация и авторизация пользователей.
  * Управление каталогом товаров и складскими остатками.
  * Работа с корзиной покупок.
  * Биллинг и оформление заказов.

### 2. FastAPI Notification & UGC-Cache (Порт `8001`)
Асинхронный микросервис для обработки тяжелых задач в фоне, чтобы не блокировать основной поток заказов в Django.
* **Технологии:** FastAPI, SQLAlchemy, Pydantic.
* **Зона ответственности:** 
  * Прием HTTP-вебхуков о новых заказах от Django.
  * Постановка задач в очередь для отложенной отправки email-уведомлений клиентам.
  * Асинхронный пересчет и кэширование среднего рейтинга товаров при появлении новых отзывов.

### 3. Flask UGC (Порт `8002`)
Изолированный легковесный микросервис для работы с пользовательским контентом (User Generated Content).
* **Технологии:** Flask, SQLite, Pydantic.
* **Зона ответственности:** 
  * Сбор и хранение отзывов и оценок к товарам.
  * Изоляция потенциально опасного контента от основной базы данных с заказами.

## Руководство по развертыванию

Проект полностью упакован в Docker. Локальная установка Python, создание виртуальных окружений или настройка баз данных не требуется.

### Шаг 1: Запуск инфраструктуры
Склонируйте репозиторий и поднимите контейнеры в фоновом режиме :
```bash
git clone <ссылка-на-ваш-репозиторий>
cd Web_Python_Falcons
docker-compose up --build -d

```

*Контейнеры автоматически настроят внутреннюю сеть, установят зависимости и инициализируют таблицы.*

### Шаг 2: Создание администратора

Для доступа к админ-панели Django создайте суперпользователя командой:

```bash
docker-compose run --rm django-web python manage.py createsuperuser

```

Панель управления будет доступна по адресу: `http://localhost:8000/admin/`


## Интеграционное E2E-тестирование

Для демонстрации работы межсервисного взаимодействия в корень проекта добавлен скрипт `test_checkout.py`. Имитирует поведение клиентского приложения.

**Жизненный цикл теста:**

1. Проходит авторизацию в Django-ядре и получает `access` токен.
2. Имитирует наличие товара в корзине пользователя.
3. Отправляет POST-запрос на оформление заказа (`/api/orders/checkout/`).
4. Django фиксирует заказ и отправляет внутренний HTTP-запрос в контейнер FastAPI.
5. FastAPI возвращает статус `202 Accepted` и начинает фоновую "отправку" письма.

**Запуск тестирования:**

```bash
pip install requests
python test_checkout.py

```
